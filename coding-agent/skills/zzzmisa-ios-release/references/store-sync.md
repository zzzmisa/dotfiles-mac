# App Storeメタデータ・素材の同期

## 変わったものだけアップロードする

- 変更のないスクリーンショットやプレビューを上げ直さない。
- スクリーンショットを同期したら、ASC APIで枚数・順序・ファイル名を確認する。
- `overwrite_screenshots` は稀に1ファイルを重複させる。`file_name` の重複を検出し、
  重複だと確認できたものだけを削除する。
- プレビュー動画はアップロード後にトランスコードされる。ポスターフレームは
  `previewFrameTimeCode` で設定する。新規アップロードではレーンの `frame_time_code` を
  使い、既存のプレビューはパッチする。

## メタデータを直接パッチする

deliverをフルで流すまでもない、文言だけの小さな修正では、ローカライゼーションを
直接パッチする:

```ruby
localization.update(attributes: { whatsNew: "..." })
```

同じ変更を `fastlane/metadata/` にも入れてPRを作る。リポジトリを正とするため。

## 検証

- 変更した全ロケール・全フィールドをASCで確認する。
- スクリーンショットの枚数・順序・重複を確認する。
- プレビューを変更した場合は、処理の完了とポスターフレームを確認する。
- 触っていない素材は変更されていないことを確認する。

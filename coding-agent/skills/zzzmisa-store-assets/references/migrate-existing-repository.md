# 既存リポジトリの素材移行

1. ファイルは `git mv` で動かす。内容が同じなら新しいblobを作らずに済む。
2. `ScreenRecording_*.mov` など内容不明の録画は、フレームを抽出して目視してから名前を付ける。既存READMEの対応表も根拠にする。
3. スクリプトが `os.path.dirname` などでリポジトリルートを求めている場合、移動後の階層の深さを確認する。
4. `rg '<旧パス>' -g '*.md' -g '*.py' -g '*.sh' -g '*.rb'` で参照漏れを探す。
5. 動画ビルドスクリプトを変更した場合、出力先を一時ディレクトリへ差し替えて既存完成品との同一性を確認する。

映像は次のSSIMで全フレーム `All:1.000000` を確認する:

```sh
ffmpeg -i new.mp4 -i old.mp4 -lavfi ssim -f null -
```

音声は両方のMD5を比較する:

```sh
ffmpeg -i <video> -map 0:a -f md5 -
```

一致しない場合、推測で式を作り直さない。以前に耳で調整した実測値をスクリプト引数として保持する。

# CLI ワーカー

ネイティブの委譲では扱えない環境や、ユーザーが指定した CLI を使う場合に読む。
固定のモデル序列や CLI オプションを推測せず、インストール済みの `--help` と
その環境で利用可能なモデルを確認する。

## Codex CLI

`codex exec` で独立した非対話作業を実行できる。モデル・作業ディレクトリ・権限設定は
現在の CLI 仕様に従い、必要なものだけ指定する。プロンプトはファイルまたは stdin で渡し、
長い本文をシェル文字列へ展開しない。サンドボックスや承認を迂回するオプションは使わない。

## GitHub Copilot CLI

指揮役の利用量を節約する選択肢。利用可能なモデルで品質を担保でき、受け入れ条件が
明確な独立作業を渡す。lint・定型修正・限定したテスト修正などが候補。
Issue 単位であっても、設計や高い判断力が必要なら指揮役が方針を決める。
委譲のためだけに追加の有料契約や設定変更を行わない。

## 実行と回収

対象範囲、受け入れ条件、検証、コミット禁止を含む指示を渡す。完了時に変更ファイルと
実行した検証・残課題を返させる。タイムアウトは完了を意味しないため、同じ領域の作業を
再開する前にワーカーの稼働状況と途中の diff を確認する。

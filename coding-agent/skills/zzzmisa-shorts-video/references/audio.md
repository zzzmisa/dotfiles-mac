# 音声設計（ナレーション・BGM・音量）

環境構築とTTSの使い方は `dotfiles-mac/tts/README.md`。ここでは動画に載せる側の設計。

## 音量設計

**目標: 完成品の Integrated を -14 LUFS 前後、True Peak を -1 dBFS 以下。**

YouTubeは-14 LUFSに正規化するが、**大きい動画を下げるだけで、小さい動画は上げない**。
-18 LUFSで書き出すと、他のShortsと並んだとき4dB小さいまま再生される。
逆に-14を超えて大きくしても下げられるだけなので、超える意味はない。

**全体を持ち上げてはいけない。ナレーションだけを上げる。**
全体にゲインをかけるとBGMまで大きくなる。BGMは連続音なので体感ラウドネスが高く、
数値以上に「うるさい」と感じられる。

```
ナレーション各行を -17 LUFS に揃える → ミックス後に声だけ +5dB
BGMは volume=0.32 のまま（変えない）
→ 全体 -14 LUFS 前後に着地する
```

`+5dB` は素材次第なので、`ebur128` を見ながら±1dBで調整する。

## BGM

- 音源: PeriTune（https://peritune.com）。2024年以降公開の曲は **CC BY 4.0**。
  商用可・YouTube可だが**説明欄へのクレジット表記が必須**:
  `BGM: PeriTune「◯◯」(CC BY 4.0) https://peritune.com`
- **楽曲ファイルの再配布は禁止**。ビルド素材としてprivateリポジトリに置くのは可だが、
  **リポジトリをpublic化する場合は必ず削除する**。READMEにその旨を明記しておく
- `volume=0.32`（元mp3から約-10dB）が基準。終端1.5秒でフェードアウト
- ナレーションがある区間だけBGMを下げる（ダッキング）:

```
[bgm][narration_copy]sidechaincompress=threshold=0.02:ratio=8:attack=20:release=500[ducked]
```

ナレーションは `asplit` で2本に分け、片方をサイドチェーン入力に使う。

## ナレーション原稿

- **キャプションと一字一句同じである必要はない**。画面はひらがな、読み上げは漢字、が正しい。
  TTSはひらがなだと読み間違えるので、**原稿は漢字で書く**
- 1行の長さは**シーンの尺 - 0.5秒**まで。フックのシーンは3秒台なので、
  日本語で16文字、英語で6語程度が上限
- 開始はシーン開始+0.45秒。頭から鳴らすと切り替わりと重なって聞き取りにくい
- エンドカードの行では**アプリ名を必ず声に出す**。Shortsにはクリックできるリンクが
  ないので、後で検索してもらうには名前が耳に残っている必要がある

### 日本語（AivisSpeech）の癖

- **読点「、」はポーズを作らない**。直前の句にモーラとして取り込まれるだけ。
  間が不自然に聞こえたら**半角スペースに置き換える**。ただし文の意味の切れ目にある
  読点は自然に聞こえることもあるので、**必ず両方作って聴き比べる**
- 複合語（特にアプリ名）は分割されて別々の語のように読まれる。
  `/audio_query` の `accent_phrases` を見れば分割位置が分かる。
  **ユーザー辞書に登録して固定する**（`dotfiles-mac/tts/aivisspeech-dict.sh`）
- `App Store` は自動で「アップストア」と読まれる（アルファベット読みにならない）

### 迷ったときの判断

音声の良し悪しはエージェントには判断できない。**候補を複数作り、0.7秒の無音を挟んで
1ファイルに連結して渡し、Misaに選んでもらう**。個別ファイルも `~/Downloads` に置くと
行き来しながら比較できる。

```sh
ffmpeg -y -f lavfi -t 0.7 -i anullsrc=r=44100:cl=stereo -i a.wav -i b.wav -i c.wav \
  -filter_complex "[1:a][0:a][2:a][0:a][3:a]concat=n=5:v=0:a=1[a]" -map "[a]" compare.m4a
```

## 素材音声を切り出す場合

外部で録音した音声などを使うときは、無音区間から各行を自動で切り出せる。

```sh
ffmpeg -i rec.m4a -af silencedetect=n=-38dB:d=0.35 -f null - 2>&1 | grep silence_
```
